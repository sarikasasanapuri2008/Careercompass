Build a lightweight MVP for "CareerCompass AI" using React (Vite), Express, SQLite (or Replit Postgres), and the @google/genai SDK (gemini-2.5-flash).

Core Objective: Build a low-resource career & exam eligibility tool with basic profile matching, rule-based eligibility, and grounded AI advice.

Key Specs & Architecture:

1. Database Schema (SQLite/Postgres):
   - `users`: id, email, age, category, degree, branch, skills (JSON string), daily_hours.
   - `opportunities`: id, title, domain ('GOVERNMENT'|'PRIVATE'), min_age, max_age, min_degree, allowed_branches (JSON string), required_skills (JSON string), official_url, last_updated.
   - Seed data: Include 3 sample Government Exams (e.g., SSC CGL, RRB NTPC, UPSC) and 3 Private Jobs (e.g., Software Engineer, Data Analyst) directly in a setup script.

2. Deterministic Eligibility Engine (Pure JS - No AI):
   - Route: `POST /api/eligibility/check`
   - Evaluate user age, degree, and branch against opportunity constraints.
   - Return status: 'ELIGIBLE', 'POSSIBLY_ELIGIBLE', or 'NOT_ELIGIBLE' with concise rule reasons.

3. Lightweight AI Endpoints (Single Gemini Flash Calls):
   - Route: `POST /api/ai/match`: Send user profile + selected opportunity. Use Gemini 2.5 Flash to return a simple JSON response: `{ "matchPercentage": number, "summary": string, "top3Gaps": string[] }`.
   - Route: `POST /api/ai/chat`: Simple RAG endpoint. Inject user profile and selected opportunity details into the system prompt. Return brief, grounded advice in 2-3 sentences max.

4. UI Layout (Tailwind CSS - Single Page with Tabs):
   - Tab 1: Profile Form (Collect age, qualification, branch, skills, category).
   - Tab 2: Opportunity Explorer (List 6 seeded opportunities with "Check Eligibility" buttons showing status badges: Green/Yellow/Red).
   - Tab 3: Simple Career Assistant (Basic chat box querying `/api/ai/chat`).

Keep all code concise, modular, and in a simple project layout (`server.js`, `db.js`, `client/App.jsx`). Do not include complex animations, background cron jobs, or heavy dependencies. Write working code in one pass.
